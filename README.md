# Data Engineering in Databricks

Este repositório foi criado para organizar meus estudos e práticas de **Data Engineering no Databricks**, com foco em ingestão de dados, processamento incremental e uso dos recursos mais atuais da plataforma. Este é um repositório de estudo e prática. Os notebooks podem sofrer alterações conforme novos conceitos forem estudados e os laboratórios forem aprimorados.
